# YouTube Analytics Dashboard

An interactive YouTube Analytics Dashboard developed using Microsoft Excel to analyze channel performance, subscriber growth, views, video performance, and overall channel trends.

## Project Overview

This project is an Excel-based analytics dashboard that converts YouTube channel data into meaningful performance insights.

The dashboard provides a centralized view of important YouTube metrics and helps track channel growth over time using KPIs, charts, tables, and visual reports.

## Key Features

- Total Subscribers KPI
- Total Views KPI
- Total Videos KPI
- Daily Subscriber Growth
- Daily Views Growth
- Average Views per Video
- Subscriber Growth Analysis
- Views Growth Analysis
- Video Performance Analysis
- Interactive charts and visualizations
- Date-based performance analysis
- Excel-based data processing and reporting
- Macro-enabled Excel workbook

## How to Use

1. Download the Excel Macro-Enabled Workbook (`.xlsm`).
2. Open the workbook using Microsoft Excel.
3. Enable macros if Excel displays a security warning.
4. Import or update the required YouTube analytics data.
5. Refresh the required data tables or pivot tables.
6. Use the dashboard to analyze channel performance.
