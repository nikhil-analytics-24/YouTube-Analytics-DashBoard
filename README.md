# YouTube Analytics Dashboard

An interactive YouTube Analytics Dashboard built using Microsoft Excel to track channel performance, views, subscribers, video growth, and engagement metrics.

## 📌 Project Overview

This project is an Excel-based analytics dashboard designed to convert YouTube channel data into meaningful visual insights.

The dashboard provides an easy way to monitor important channel performance metrics and understand growth trends over time.

## 🎯 Project Objectives

- Track total subscribers
- Monitor total channel views
- Analyse video performance
- Track daily subscriber growth
- Track daily views growth
- Calculate average views per video
- Analyse subscriber growth trends
- Analyse views growth trends
- Present important KPIs in an interactive dashboard

## 📊 Dashboard Features

### KPI Cards

The dashboard includes important performance indicators such as:

- Total Subscribers
- Total Views
- Total Videos
- Daily Subscriber Gain
- Daily Views Gain
- Average Views per Video

### 📈 Growth Analysis

The dashboard provides visual analysis of:

- Subscriber growth over time
- Views growth over time
- Daily performance changes
- Video-level performance

### 📊 Charts and Visualizations

The project uses Excel charts and visualizations to make YouTube analytics easier to understand.

The dashboard includes:

- Subscriber Growth Line Chart
- Views Growth Line Chart
- Video Performance Bar Chart
- Category/Performance Donut Chart
- KPI Cards
- Date-based analysis
